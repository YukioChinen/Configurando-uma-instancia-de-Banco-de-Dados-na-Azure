# Configurando uma instância de Banco de Dados na Azure
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO.

- IaaS (Infraestrutura como Serviço): Você gerencia VMs, redes e armazenamento; a Azure cuida da infraestrutura física. Ideal quando você precisa de controle total sobre o ambiente.
- PaaS (Plataforma como Serviço): A Azure fornece ambiente de desenvolvimento pronto (como App Services). Você foca no código; ideal para desenvolvedores.
- SaaS (Software como Serviço): Aplicações prontas (como Microsoft 365), gerenciadas totalmente pela Azure. Ideal para uso direto, sem preocupação com infraestrutura.

A Microsoft cuida da segurança da nuvem, e o cliente é responsável pela segurança na nuvem, variando conforme o modelo.

Quando usar cada modelo:
- IaaS: Quando precisa migrar sistemas legados ou personalizar a infraestrutura.
- PaaS: Quando quer desenvolver aplicações rapidamente sem gerenciar servidores.
- SaaS: Quando quer usar software pronto com mínima gestão técnica.
